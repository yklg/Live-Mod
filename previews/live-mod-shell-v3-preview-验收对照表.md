## 3. 怎么看

1. **左右对比**：默认页即左右并排；顶栏「前后对比」可切换成单窗口模式。改动点徽章只出现在右侧。
2. **明暗切换**：顶栏「切换暗色 / 切换亮色」，全页生效并按本机记忆持久化。
3. **引导**：顶栏「引导」按 6 步走完主流程（对比 → 顶栏按钮 → 悬浮列表 → 浮层面板 → 评论区状态 → 连接错误分类），支持上一步 / 跳过。
4. **状态控制台**：右下角「设」按钮 → 全局网络模式 + 当前页数据区状态 + 改动点速览 + 重置。
5. **链路图 / 验收**：顶栏对应按钮，分别打开抽屉与验收面板。
6. **动效**：标准模式 180ms 淡入 + 位移、出现/收起对称；系统开启「减少动态效果」时自动瞬时；拖拽期不演示。跑 `node previews/preview-animation.spec.mjs` 可复现 §2.1 全部 28 条断言。
